# Каталог фильмов (Movie Catalog API)

Простое и эффективное REST API приложение для поиска, фильтрации и просмотра информации о фильмах различных жанров.

## Основные возможности приложения
* Получение списка фильмов, сгруппированных по жанрам.
* Гибкая фильтрация фильмов по минимальному рейтингу (`min_rating`) и конкретному году выпуска (`year`).
* Поиск подробной информации о конкретном фильме по его названию внутри выбранного жанра.
* Валидация входящих параметров (ограничения на диапазоны рейтинга и годов выпуска).

## Технологический стек
* **Язык программирования:** Python 3.10+
* **Фреймворк:** FastAPI
* **ASGI-сервер:** Uvicorn

## Основные эндпоинты

### 1. Получение фильмов по жанру с фильтрацией
* **URL:** `/movies/{genre}`
* **Метод:** `GET`
* **Параметры пути (Path):**
  * `genre` (string): Жанр фильма (`action`, `drama`, `comedy`).
* **Параметры запроса (Query):**
  * `min_rating` (float, по умолчанию `0.0`): Минимальный рейтинг фильма.
  * `year` (int, необязательный): Конкретный год выпуска фильма.

### 2. Получение конкретного фильма по названию
* **URL:** `/movies/{genre}/{title}`
* **Метод:** `GET`
* **Параметры пути (Path):**
  * `genre` (string): Жанр фильма.
  * `title` (string): Название фильма (регистронезависимое).

## Фильтрация и сортировка
* **Фильтрация по рейтингу:** Валидируется с помощью параметров FastAPI `Query(ge=0.0, le=10.0)`. Фильмы с рейтингом ниже указанного автоматически отсекаются.
* **Фильтрация по году:** Валидируется в диапазоне `Query(ge=1900, le=2025)`. Возвращаются только фильмы, чей год строго совпадает с переданным.
* **Сортировка:** В текущей итерации явная сортировка результатов отсутствует; данные отдаются в порядке их расположения в коллекции.

## Модель данных
Каждая запись о фильме представляет собой объект со следующей структурой:
```json
{
  "title": "Название фильма (строка)",
  "year": "Год выпуска (целое число)",
  "rating": "Рейтинг фильма (дробное число)"
}
```

## Ограничения базы данных
Так как полноценная СУБД в проекте на данный момент отсутствует, все ограничения реализованы на уровне валидации слоёв FastAPI (`Path` и `Query`):
* Рейтинг фильма должен быть строго в диапазоне от `0.0` до `10.0`.
* Год выпуска фильма должен находиться в промежутке от `1900` до `2025` года.
* При попытке запросить несуществующий жанр или фильм приложение возвращает структурированный ответ об ошибке или HTTP-исключение `404 Not Found`.
